# ADR-003: Observation remains a debug feasibility probe

12 November 2026. Accessibility plus usage access remains the proposed production
strategy. Current probe observes only allowlisted package/event metadata after
opt-in; it does not retrieve content. A safe Home redirect is selectable only for
one native test package. Settings/disable routes remain reachable. No force-stop,
continuous screenshots, OCR or additional privilege is introduced.

Physical source/duration/re-entry/precision/battery evidence is still required.
Instagram and X native packages are unavailable on the attached phone. All
classification rows stay pending. I10–I12 production work must wait for these gates;
independent manual Focus and Training work may proceed. No optional vision choice
is made without further explicit requirements and device evidence.
